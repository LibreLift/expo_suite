# expo_suite

Source code for LibreLift mobile app. Built with React Native Web and Expo framework.

## Design

The design document for this project is found [here](./docs/design.md). It outlines the following elements of the project:

- Context and scope
- Goals and non-goals
- System-context diagram
- Components - includes component diagram and step-by-step user flow
- Data model and ERD
- Technology decisions and explanations
- Risks and open questions
- Implementation steps and milestones

This is the starting point for understanding this project and preparing to contribute to it.
